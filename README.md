# gamers.inc_datapack
datapack for gamers.inc

## spawn_tp
adds a command to tp to a location marker named "spawn", using \trigger spawn_tp

## pegasus
allows "pocket horses", once setup, players can use \trigger horse_load and \trigger horse_unload to teleport their horse from "stable" location to their current position and vice versa. Adds Information about a horses jump, speed, and health, using the \trigger horse_info command. currently bugged in 1.21

## creative zone
provides functionality for adding a creative dimension in a survival world, they spawn structures which can be right clicked whith an empty inventory to teleport to the creative dimension, can be exited with /trigger creatent

## elemental_powers
adds a power and type/class system to minecraft based on 10 elemental types. currently in developement, only partial functionality, must be set up via commands

## custom food
adds new crops, fishes and fruits which can be accessed depending on the biome and other conditions.

## enchanted core
adds a system to absorb enchantments to later be applied to other items, absorbs at 33% efficiency. to access the system hold a book and use \trigger absorb enchants. to enchant or absorb hold the weapon tool or armor in the left hand and use the book with the main hand. incompatible with custom enchants.

## extra biome ores
adds a rare gold geode in mesa biomes, similar to amethyst geodes. is heavily affected by terrain generation datapacks

## hide n seek
adds a structure and functionality to play hide and seek in minecraft. currently must be spawned in through commands

## ipod
adds a craftable ipod which can record found music discs to then be replayed at any moment. uses \trigger commands and right/left clicks. will be updated with dialog system.

## custom structures
adds giant ancient rails to the overworld, providing extra powered rails, or a quick way to go in a straight line, or through a mountain. also helps add extra landmarks to the landscape.
Adds adventure camps, small tents with a bed and chest to rest. can contain maps to structures in semi rare biomes, or to ancient libraries.
Adds ancient outposts, small towers in mountains with chests that contain ingredients for recovery compasses.
Adds courthouse, a small structure, pretty rare.
Adds a rare big house with xiao's spear in a item frame.
Adds purple sail ships in the oceans, with beds for resting and a cartographer villager.

## tweaks
changes lodestone recipe to be cheaper, adds bundle crafting recipe, adds apple cake and pozol recipes.

## world teleporters
Adds ancient libraries which can be linked to function as overworld waypoints and teleporters. obtain the teleport book for a specific library by right clicking the pray text. open the book manually or in a lectern while in a ancient library to teleport to the corresponding library. teleporting while wearing an elytra will spawn you high in the sky.
